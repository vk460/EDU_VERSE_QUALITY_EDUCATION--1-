## Project Description
EduVerse Frontend is a high-fidelity, immersive user interface designed for the EduVerse AI-driven educational platform. It provides a premium, "Quantum Cinema" inspired experience, featuring 3D interactive elements, smooth animations, and a modern glassmorphism aesthetic. The project serves as the central hub for interacting with various AI agents including Research, PDF/RAG, and Communication assistants.

## Tech Stack
- **Core**: React 19 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **3D/Graphics**: Spline, Three.js, React Three Fiber
- **Icons**: Lucide React
- **Utilities**: clsx, tailwind-merge, tailwindcss-animate

## How to Run
1. Clone the repository.
2. Navigate to the `Frontend` directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Local Server (Optional)
If you need to run the Python bridge or local server:
```bash
python app.py
```
